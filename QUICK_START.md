# Quick Start Guide - News Fact Validation with GNN

## Complete System Overview

This system combines:
1. **LLM** (OpenAI GPT) - Entity/event extraction
2. **Knowledge Graph** - Temporal fact representation
3. **GNN** (Graph Neural Network) - Pattern-based fact verification
4. **Symbolic Logic** - Rule-based contradiction detection

- ✅ Mock training data generated (100 samples)

## Quick Commands

### 1. Test GNN Model (No API Calls)
```bash
python test_gnn_demo.py
```
This verifies the GNN model is working.

### 2. Run Full Demo (Requires API Access)
```bash
python demo.py
```
This runs the complete pipeline with real LLM calls.

### 3. Generate More Mock Training Data
```bash
python generate_mock_llm_data.py --num_samples 200
```

### 4. Train GNN with More Data
```bash
python train_gnn.py --use_llm_log --llm_log_limit 200 --epochs 50
```

### 5. Inspect Data Quality
```bash
python inspect_llm_extractions.py
```

## What Happens When You Run demo.py

```
1. 🤖 Initialize LLM Client
   ↓
2. 🔬 Extract Entities, Events, Relations (LLM call)
   ↓
3. 🕸️  Build Temporal Knowledge Graph
   ↓
4. 🤖 GNN Analysis (if model exists)
   → Predicts: SUPPORTS or REFUTES
   → Shows confidence score
   ↓
5. 🧠 Apply Symbolic Logic Rules
   → Detects contradictions
   ↓
6. ✍️  Generate Corrected Narrative (LLM call)
   ↓
7. 📊 Create Visualizations
   → Interactive graph
   → Timeline view
   → Full report
```
